# YepTennis

First design prototype for yeptennis.com.

## Files
- `index.html` — homepage
- `style.css` — responsive visual design
- `app.js` — small interactive elements
- `assets/` — reserved for local images

## Deploy
This is a static website and can be deployed directly to GitHub Pages, Cloudflare Pages, or a Cloudflare Worker/static-assets setup.

The current prototype uses Unsplash-hosted photography for visual placeholders. Before public launch, replace these URLs with licensed/local tennis images.

## Next step
Connect live ATP/WTA tournament data, results, rankings and a news feed through APIs/Cloudflare Worker endpoints.
